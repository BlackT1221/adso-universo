# API Universo ADSO - Reto de Código Abierto

¡Bienvenidos a su primera contribución Open Source! El objetivo de esta actividad es que agreguen su propio personaje a la API oficial de la clase utilizando Git.

## Misión: Agrega tu Personaje

Sigue estos pasos desde tu terminal para enviar tu personaje:

**1. Haz Fork de este repositorio** (Clic en el botón 'Fork' arriba a la derecha en GitHub).

**2. Clona TU fork en tu computadora:**
```bash
git clone https://github.com/TU_USUARIO/adso-universo.git
cd API-ADSO-Universo
```

**3. Crea una nueva rama (branch) con tu nombre:**
```bash
git checkout -b feature/personaje-tunombre
```

**4. Escribe tu código:**
Abre el archivo `routers/personajes.py` y agrega tu diccionario a la lista `UNIVERSO`.

**5. Guarda tus cambios (Commit):**
```bash
git add .
git commit -m "Agrega el personaje de [Tu Nombre]"
```

**6. Sube los cambios a tu GitHub:**
```bash
git push origin feature/personaje-tunombre
```

**7. Abre el Pull Request:**
Ve a GitHub y haz clic en el botón verde "Compare & pull request" para enviar tu personaje al repositorio del Instructor. ¡Espera a que sea aprobado en vivo!
